# 🎓 Student Gradebook & Course Manager

A simple Python project for managing students, courses, assessments, and grades using Object-Oriented Programming (OOP).

This project was developed as the final project for my Python programming course.

---

## Demo



https://github.com/user-attachments/assets/a12e3539-8198-4cfc-9eac-9605b7cec1af



## ✨ Features

- Add new students
- View all students
- Search students by ID or name
- Update student email
- Delete students
- Add new courses
- Enroll students in courses
- Add different assessment types:
  - Quiz
  - Exam
  - Project
- Record student grades
- Calculate average grades
- Display student reports
- Show letter grades (A–F)
- Dashboard
- Top student
- Course statistics

https://github.com/FatemeHeydariii/Student-Gradebook-Course-Manager.git

'''bash

'''

'''bash
python main.py
